# OpenYAMM Atlas 0.3.0

Windows x64 preview, 17 November 2026. Based on OpenYAMM 2.6.

- Ported the native MM6, MM7 and MM8 Atlases to 2.6's shared `core` structure and save format 191.
- Added the complete MM6 Atlas: 15 regions and 40 playable dungeon maps.
- Added English/Polish Atlas display hooks and the Polish supplement.
- Added a persistent main-menu on/off button. The Atlas opens from the Map Book; disabling it retains discoveries and notes.
- Retained discovery fog, party tracking, notes, search and incremental Guide indexing.
- Added a small Windows package with a pinned 2.6 content downloader and reuse of matching existing packs.

## Checks

Atlas/localization: 91 cases / 5,304 assertions. Input: 25 cases / 278 assertions. Installed-map audits: 4,146 assertions in English and 4,149 in Polish, covering 204 programs and 203 geometries. The toggle adds 34 focused cases / 4,394 assertions and native restart/keyboard/PL/EN checks. MM6/MM7/MM8 native Windows views and isolated save migration/exchange passed.

These are focused checks, not complete campaign playthroughs. Android and physical-controller acceptance on this base remain pending. No MM9 Atlas is included.

## Install and saves

Extract into a new folder and run `Play Atlas.cmd`. The ZIP contains no multi-gigabyte runtime packs; first setup fetches the matching 2.6 content from official hosting. See [installation and cache reuse](../../../ATLAS_RELEASE.md).

Back up saves before changing builds. Test copies of 2.5 saves migrated successfully. Official 2.6 resaves discard the supplemental Atlas trailer, so round trips do not preserve all Atlas knowledge. New 2.6 saves are not promised readable by 2.5.

The source also includes the independent Polish MM9 importer and a local-catalog fix. Retail recordings, movies and private review data are not distributed in this release.
